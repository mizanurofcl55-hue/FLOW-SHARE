FlowShare shares files locally over Wi-Fi, Ethernet LAN or a temporary hotspot. No account or cloud transfer server is required.

**This is a LAN/hotspot preview.** Both devices must join a reachable local network. Nearby Connections, Wi-Fi Direct/Aware and Apple peer-to-peer are not included. Physical cross-device transfer testing and production signing are still pending.

## Choose your download

| Device | File | Install / use |
|---|---|---|
| Most modern Android phones | `FlowShare-0.1.0-Android-arm64-Preview.apk` | Download and open the APK; allow installation from that source only if you trust this preview. |
| Older 32-bit Android phones | `FlowShare-0.1.0-Android-armv7-Preview.apk` | Use only when ARM64 is unsupported. |
| Android x86_64 emulator | `FlowShare-0.1.0-Android-x86_64-Preview.apk` | Emulator / compatible x86_64 devices. |
| Windows x64 | `FlowShare-0.1.0-Windows-x64-Preview.zip` | Extract the entire ZIP and run `flowshare.exe`; keep its DLLs and data folder together. |
| macOS developers | `FlowShare-0.1.0-macOS-Unsigned-Preview.tar.gz` | Unsigned debug bundle; local signing and OS validation are required. |
| iOS developers | `FlowShare-0.1.0-iOS-Unsigned-Developer-Build.tar.gz` | Unsigned `.app`, **not an installable IPA**; requires Xcode, an Apple team and provisioning. |

Android APKs are debug-signed testing builds. A new CI debug key can prevent updating a previously installed preview. Removing the old app can remove its local history and received files, so preserve those first. This release is not Play Store / App Store distribution. Do not disable device security protections to install a blocked build.

## Send a file

1. Join the same reachable LAN, or connect the second device to a hotspot. Internet is not needed for the file transfer.
2. Recipient: **Receive files → Start receiving**.
3. Sender: choose files, find the device, or paste/scan its pairing link.
4. Compare all four verification-code groups on both devices and approve on both.
5. Keep both apps open until completion. Files are SHA-256 verified before successful receipt is reported.

The QR code pairs devices; it does not join Wi-Fi automatically. Interrupted files restart; already verified complete files can be reused on retry. Received files stay in app-private storage; open them in a compatible app to export.

## বাংলা নির্দেশনা

সাধারণ Android ফোনের জন্য **arm64 APK** ডাউনলোড করুন। দুই ডিভাইস একই Wi-Fi বা একটির hotspot-এ যুক্ত করুন। গ্রহণকারী **Receive files → Start receiving** চাপবে। প্রেরক ফাইল বেছে ডিভাইস খুঁজবে বা QR/pairing link ব্যবহার করবে। দুই ডিভাইসের চারটি verification-code group মিলিয়ে উভয় দিক থেকে অনুমতি দিন। পাঠানো শেষ না হওয়া পর্যন্ত অ্যাপ খোলা রাখুন। এটি পরীক্ষামূলক সংস্করণ; সরাসরি Nearby/Wi-Fi Direct এখনো নেই।

## Verify and report

`SHA256SUMS.txt` contains the checksums of every download. `build-provenance.json` identifies the exact source and build/test runs. On Windows use `Get-FileHash <file> -Algorithm SHA256`; on macOS use `shasum -a 256 <file>`; on Linux use `sha256sum <file>`.

Report problems at https://github.com/mizanurofcl55-hue/FLOW-SHARE/issues with OS version, app version, connection type, steps and the error message. Avoid posting private filenames, pairing links or personal data.
