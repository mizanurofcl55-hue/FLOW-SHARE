# Changelog

## 0.1.0 preview

- Real authenticated local TLS transfer, bounded streaming and verified completed-file retry.
- Cross-platform Flutter screens, native file selection, desktop drop, QR/manual pairing and real mDNS.
- English/Bengali, responsive navigation, light/dark themes and original branding.
- Local SQLite history, OS-protected identity and explicit incoming approval.
- Android local-only hotspot and visible active-transfer service.
- Automated protocol/security/UI/database checks and native build workflows.
- QR decoding in Dart on Android/iOS, with no ML Kit dependency or audio recording; desktop discovery/manual pairing.
- Installed-APK Android emulator checks and resolved Android dependency privacy checks.
- Fixed live updates in routed screens for receiving, selected files, progress, discovery and errors; added a routed-screen regression test.
- Explicit limitations for unimplemented direct transports, physical testing and production signing.
